# 🍋 Master Frontend

This repository contains my learning journey through the **Master Frontend** program by Lemoncode - an intensive, hands-on specialization in frontend development.

---

### **About the program**

A comprehensive master's program focused on training specialized frontend developers, covering everything from responsive layout and modern JavaScript to frameworks, testing, REST API integration and cloud deployment.

Taught by experienced developers with a practical, real-world approach and an agile methodology.

---

### **Curriculum**

**Module 0 · UX**
* User Experience fundamentals
* Design for developers
* Figma
* Design patterns

**Module 1 · Layout**
* HTML5 + CSS3 basics
* Responsive layout
* SASS
* CSS animations
* From Figma to CSS

**Module 2 · JavaScript & TypeScript**
* JavaScript ES5 / ES6+ / ES7
* TypeScript
* Functional programming
* Lodash

**Module 3 · Bundling**
* Webpack
* Vite

**Module 4 · Frameworks**
* React - components, hooks, navigation, data access, CSS in JS, Next.js
* Angular - architecture, services, RxJS
* Vue.js - Composition API, VueRouter, async setup
* Svelte, SolidJS, Lit, Astro, D3.js, Web Components
* Micro Frontends · Accessibility · SOLID principles

**Module 5 · Testing**
* Jest / Vitest · Mocking · React Testing Library
* Code coverage · Continuous integration
* E2E testing: Cypress, Playwright

**Module 6 · REST API Integration**
* Fetch · Axios · GraphQL · Socket.io
* Security: JWT, Cookie / Header, OAuth 2.0
* CORS

**Module 7 · Cloud Deployment**
* Docker · Azure · Amazon AWS · Render
* GitHub Actions + Turbo Repo + Changeset

**Module 8 · Mobility**
* PWA · React Native

---

### **Technologies**

HTML5, CSS3, SASS, JavaScript (ES6/ES7), TypeScript, React, Next.js, Angular, Vue.js, Svelte, Figma, Flexbox, CSS Grid, Webpack, Vite, Jest, Vitest, GraphQL, Docker, Azure, AWS, Git, GitHub
